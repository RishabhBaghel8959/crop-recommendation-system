# 🌱 AI Crop Recommendation System

A Machine Learning-powered web application that helps farmers choose the most suitable crop to grow based on environmental factors like soil nutrients and weather conditions.

## 🚀 Features
* **Smart Predictions:** Recommends crops based on Nitrogen (N), Phosphorous (P), Potassium (K), Temperature, Humidity, pH, and Rainfall.
* **Interactive UI:** Built with Streamlit for a clean and user-friendly experience.
* **Data-Driven:** Uses a Machine Learning model trained on soil and weather datasets.

## 🛠️ Tech Stack
* **Language:** Python 3.12
* **Frontend:** [Streamlit](https://streamlit.io/)
* **ML Libraries:** Scikit-learn, Pandas, NumPy
* **Environment:** Virtualenv
